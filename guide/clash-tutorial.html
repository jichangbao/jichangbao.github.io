Clash 机场推荐与使用教程：Windows、Mac、安卓、iPhone 导入订阅

买好机场后会拿到一个订阅链接，导入客户端就能用。本站推荐的机场都支持 Clash 订阅一键导入。

支持 Clash 的机场推荐

sogo云（VLESS 协议，需要 Clash Meta / Mihomo 内核，Clash Verge Rev 已内置）、飞猫云、暮光、微风，完整名单见 机场推荐排行榜。

第 1 步：下载 Clash Verge Rev

到 GitHub 上的 clash-verge-rev 项目页面，在 Releases 里下载：Windows 选 x64-setup.exe，苹果 M 系列芯片选 aarch64.dmg，Intel Mac 选 x64.dmg。只从官方项目页下载。

第 2 步：复制订阅链接

登录机场官网 → 仪表盘 → "复制订阅链接"或"一键订阅 → Clash"。订阅链接相当于账号密码，不要发给别人。

第 3 步：导入订阅

  1. 打开 Clash Verge Rev，点左边"订阅"。
  2. 把订阅链接粘贴到顶部输入框，点"导入"。
  3. 点一下这个订阅让它变成选中状态。

第 4 步：选节点并开启代理

  1. 点"代理"，模式选规则（国内直连，国外走代理）。
  2. 选择节点，可以点测速图标挑延迟低的。
  3. 在"设置"打开系统代理。

手机和其他客户端

系统客户端导入方法
Windows / MacClash Verge Rev、Mihomo Party、v2rayN订阅 → 粘贴链接 → 导入
安卓Clash Meta for Android、Hiddify配置 → 新建 → 从 URL 导入
iPhone / iPadShadowrocket、Stash、Loon外区 Apple ID 下载，机场官网"一键导入"
路由器OpenWrt、ShellClash按插件说明填订阅链接

常见问题

  • 导入失败：检查链接是否完整；或先开一个能用的节点再更新订阅。
  • 能连上但打不开网页：换节点，或把模式改成"全局"测试。
  • 节点全部超时：点订阅"更新"，机场可能换了地址。
